# CCNA 200-301 Study Notes (Multi-Source)

Este repositório contém minhas anotações de estudo para a certificação Cisco CCNA 200-301, combinando dois excelentes recursos gratuitos para um aprendizado completo:

1. **Jeremy's IT Lab** (Teoria e Labs em Packet Tracer)
2. **David Bombal** (Demonstrações Práticas com Equipamentos Reais e Wireshark)

## Estrutura do Repositório

O repositório está organizado por fonte de estudo, com diretórios separados para facilitar o acompanhamento paralelo:

* **`jeremys-lab/`**: Contém as anotações e templates para o curso do Jeremy's IT Lab (63 dias).
* **`bombal-course/`**: Contém as anotações e templates para o curso prático do David Bombal (37 vídeos).
* **`templates/`**: Contém os modelos padrão utilizados para registrar as anotações.

## Como usar este repositório

1. Ao iniciar um novo tópico, copie o template correspondente para o diretório da fonte de estudo.
2. Preencha o template com suas anotações sobre os vídeos e os laboratórios práticos.
3. Commit e push suas alterações para manter seu progresso salvo no GitHub.
